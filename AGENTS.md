# Project access rules

- For user-requested tasks, you may read, create, edit, and delete the relevant files inside this project.
- Outside this project, access is read-only. Do not create, edit, or delete external files, including through symlinks that resolve outside the project.
- Keep temporary files, caches, and generated artifacts inside the project.
- Preserve unrelated user changes.
- Respect enforced sandbox restrictions and approval requirements; do not bypass them to obtain write access.
